index.html is included for browser-based modules.

RUN WITH NODE.JS:
1. Open the folder in VS Code.
2. Open Terminal.
3. Example:
   node module1.js
4. Repeat for modules that do not require browser APIs.

RUN BROWSER MODULES:
1. Open index.html in a browser or use VS Code Live Server.
2. Uncomment the required script in index.html.
3. Open browser Developer Tools -> Console.

Important:
module6.js, module7.js and module11.js use browser APIs.
module10.js uses fetch() and can run in a modern browser or Node.js.
